# Swift Coding Rules

For `.swift` work, including `Package.swift`, read [references/swift.md](references/swift.md) completely and treat it as the only normative agent rule set.

[references/swift.ja.mdx](references/swift.ja.mdx) is a translation for humans. Do not load both language versions unless the user explicitly requests Japanese.

[references/sources.md](references/sources.md) records official sources, research date, version caveats, and the rationale for Swift-specific adaptations. Read it when checking version-sensitive behavior or updating these rules; it is not an additional rule set.
